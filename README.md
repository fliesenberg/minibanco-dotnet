# MiniBanco.ConsoleApp: Motor de Gestão de Contas Bancárias

MiniBanco.ConsoleApp é um aplicativo Console escrito em C# .Net para gestão de contas bancárias. Este projeto é um mini-projeto avaliativo para o curso de Desenvolvimento Back-end .Net do SCTec.

# Como Executar

## 1. Clonar o repositório
git clone https://github.com/fliesenberg/minibanco-dotnet

## 2. Entrar na pasta do projeto
cd minibanco-dotnet

## 3. Abrir o VS Code na pasta do projeto
code .

## 4. Abrir o terminal do VS Code
Ctrl + '

## 5. Fazer o build do projeto
dotnet build

## 6. Rodar o aplicativo
dotnet run

# Tecnologias Utilizadas

* Linguagem C#
* .Net 10.0
* Aplicativo Console

# Funcionalidades

## Funções do Menu Principal

* 1 - Abrir Nova Conta
* 2 - Registrar Movimentação
* 3 - Aplicar Fechamento Mensal
* 4 - Exibir Relatório das Contas
* 0 - Sair
